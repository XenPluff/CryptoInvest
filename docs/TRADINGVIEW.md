# TradingView homepage market display

Live at <https://aureon-preview.onrender.com>, deployed from source
`ea29c0b8fbb12c9fad108f081bd0e1a0dd704fbb` in Render deployment
`dep-dbh40gbbc2fs73emb4ig`.

The homepage market strip uses TradingView's public Ticker Tape iframe, with
native provider branding and a linked “Track all markets on TradingView” credit.
It replaces `MarketTicker`'s `/api/markets` polling, stale-data indicator,
“FEED UNAVAILABLE” state and custom asset links. Other market pages and deposit
price calculations retain their existing providers and behavior.

The configured instruments and quote currencies are explicit:

| Display | TradingView instrument |
| --- | --- |
| Bitcoin / USD | `COINBASE:BTCUSD` |
| Ethereum / USD | `COINBASE:ETHUSD` |
| Tether / USD | `COINBASE:USDTUSD` |
| BNB / USDT | `BINANCE:BNBUSDT` |

Prices, percentage changes, symbols and ticker movement are rendered by the
provider. There are no hardcoded quotes, simulated changes or application-side
price substitutions. The provider's symbol links open its market information.
The attribution link remains available if a browser blocks the widget.

`components/MarketTicker.tsx` uses the iframe endpoint generated by TradingView's
[official embedding script](https://s3.tradingview.com/external-embedding/embed-widget-ticker-tape.js)
and described in its [Ticker Tape documentation](https://www.tradingview.com/widget-docs/widgets/tickers/ticker-tape/).
The iframe is isolated on `www.tradingview-widget.com`. The first-party CSP adds
only this `frame-src` origin; external first-party scripts and external
first-party connections are still disallowed. TradingView's own frame manages
its scripts, symbols and live quote connection. The application requires no
TradingView account credentials or private API key for this public widget.

The iframe uses the website's dark/light preference and reloads when its theme
or provider locale changes. The credit is translated in all eight site languages.
Supported provider locales are selected explicitly; TradingView does not list
Ukrainian for this widget, so the Ukrainian site uses the English provider UI
with Ukrainian attribution. The ticker keeps its own left-to-right layout and
uses the provider's fonts. The full-width 58px frame and 32px credit reserve
approximately the same 90px space as the prior strip, including narrow screens.

## Validation

- Production Next.js build and client/server TypeScript checks pass.
- All six existing localization/catalog checks pass, including the new credit.
- Actual provider data renders for all four instruments. The local verification
  observed 53 quote frames and 51 price updates, with no provider socket errors.
- Six 1440/390/320px dark/light states fit without document overflow and retain
  attribution. The ticker advances, and all eight language selections match the
  configured provider locale and translated credit.
- The former ticker markup and its `/api/markets` request are absent.

Local browser verification uses a fixture only for the application's public
content GET. Provider HTTP responses and WebSocket messages are real. Because
the cloud browser lacks the workspace proxy CA, ignored verification tooling
relays HTTPS and live WebSockets through the environment's trusted client,
retaining certificate verification and the provider origin. No TLS checks are
disabled. This relay is not part of the application or deployment.

Artifacts and reproduction tools are ignored local files in
`.aureon/tradingview/`: `local-result.json`, `local-browser.log`, `build.log`,
`i18n-test.log`, and theme/width screenshots. `check-widget.mts` runs the same
checks against hosted HTML and actual GET APIs with `TRADINGVIEW_HOSTED=1`.
No deposits, account changes, transactions or emails are created.

## Hosted verification

The deployed page repeats all six focused checks: CSP isolation, four actual
provider prices, removal of the old strip/API dependency, six responsive/theme
states, advancing ticker content, and all-eight-language widget configuration
and translated attribution. It uses actual hosted HTML, assets and content GET
APIs, with no API fixtures or production mutations. The run observed 57 real
quote frames and 54 price updates over nine provider connections, without page,
provider-request or socket errors. No financial records or emails were created.

Health reports HTTP 200, connected database, enabled funding and passed email
readiness. The seven globe-logo SVGs and globe poster also match their unchanged
source hashes. Results: `.aureon/tradingview/hosted-result.json` and
`.aureon/validation/tradingview-hosted-assets.json`; screenshots are
`.aureon/tradingview/hosted-{dark,light}-{1440,390,320}.png`.

Automatic deployments remain disabled. Documentation commits after the deployed
source above do not change the running version.
