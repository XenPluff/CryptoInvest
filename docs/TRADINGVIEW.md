# TradingView homepage market display

Live at <https://aureon-preview.onrender.com>, deployed from source
`b4355d76258f29105afb5e48198055ea364236e4` in Render deployment
`dep-dbh4qt59fdbs738c77j0`.

The homepage uses TradingView's public Ticker Tape iframe with its native
provider logo and market links. The owner-requested removal of the separate
“Track all markets on TradingView” text link is live. Its wrapper and styles
are removed, leaving a 58px iframe inside a 60px bordered band on desktop and
mobile, without the former 32px text row.

| Display | TradingView instrument |
| --- | --- |
| Bitcoin / USD | `COINBASE:BTCUSD` |
| Ethereum / USD | `COINBASE:ETHUSD` |
| Tether / USD | `COINBASE:USDTUSD` |
| BNB / USDT | `BINANCE:BNBUSDT` |

The provider renders prices, changes and ticker content. There are no hardcoded
quotes or application-side price substitutions. The homepage's former
`/api/markets` poll and unavailable-feed strip remain removed. Other market
views and deposit price calculations retain their existing providers.

`components/MarketTicker.tsx` uses the iframe endpoint generated by TradingView's
[official embedding script](https://s3.tradingview.com/external-embedding/embed-widget-ticker-tape.js)
and described in its [Ticker Tape documentation](https://www.tradingview.com/widget-docs/widgets/tickers/ticker-tape/).
The provider iframe is isolated on `www.tradingview-widget.com`. The first-party
CSP permits only this external frame origin and still disallows external
first-party scripts/connections. No private TradingView credentials are needed.

The iframe matches the site's dark/light theme and supported provider locale.
All eight site language selections are handled; TradingView does not list
Ukrainian for this widget, so Ukrainian uses its English provider UI. Provider
fonts, logos and quote-pair labels remain inside the unchanged iframe.

## Validation

The production build and client/server type checks pass. Six focused local and
hosted browser checks verify real quotes for all four instruments, the unchanged
CSP isolation, absence of the old strip/API poll, a compact 60px band without
parent text links in six 1440/390/320px dark/light states, continuing provider
price updates, and all eight site language selections.

The hosted run uses actual HTML, assets, public content GET APIs and provider
HTTP/WebSocket responses, without API fixtures or production mutations. It
observes 55 real quote frames and 51 price updates over nine connections,
with no page, provider-request or socket errors. Public health is HTTP 200,
with connected database, enabled funding and passed email readiness.

Continuity is checked using incoming quote messages, since market prices can
remain unchanged between short screenshot samples. The cloud browser's trusted
HTTPS/WebSocket relay retains TLS verification and is ignored test tooling;
it is not deployed. Local fixtures cover only the app's public content GET.
No provider prices are simulated and no financial records or emails are created.
